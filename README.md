# ● ドットカフェ モバイルオーダーシステム

文化祭限定のドットカフェをイメージした、スマートフォンから注文できるレトロポップなWebアプリケーションです。

お客さんが自分のスマートフォンから商品を注文し、店員はPCから注文状況や在庫を管理できるシステムを目指します。

## 🎯 プロジェクトの目的

- 注文受付を効率化する
- 注文の間違いや受け渡しミスを減らす
- 商品の在庫をリアルタイムで管理する
- お客さんがスマートフォンから簡単に注文できるようにする

## 🛠 使用技術

| 技術 | 用途 |
|---|---|
| HTML | Webページの構造 |
| CSS | デザイン・レイアウト |
| JavaScript | 画面操作・注文処理 |
| Firebase Hosting | Webサイトの公開 |
| Cloud Firestore | 商品・注文・在庫データの保存 |
| Firebase Authentication | 店員のログイン認証 |
| Cloud Functions for Firebase | 注文確定・在庫更新などのサーバー側処理 |

## 🏗 システム構成

1. お客さんがWebサイトから商品を選択する
2. 注文内容を確認して注文を確定する
3. サーバー側で在庫を確認し、注文情報を保存する
4. 店員用管理画面に注文が反映される
5. 店員が調理状況を更新する
6. お客さんが注文状況を確認する

## 🔐 セキュリティ方針

- 店員用管理画面は認証を必須にする
- Firestore Security Rulesでアクセス権限を制限する
- 在庫確認と注文確定は信頼できるサーバー側処理で行う
- クライアントから送信された価格や合計金額をそのまま信用しない
- Firebaseの秘密鍵や認証情報をGitHubに公開しない

## 現在の実装について

現在は外部サービスの設定なしで動作を確認できるプロトタイプです。商品・在庫・注文はブラウザのlocalStorageに保存され、店員画面のデモコードは `cafe2025` です。

本番公開前には、localStorageの処理をCloud Firestoreへ置き換え、Firebase Authentication・Cloud Functions・Firestore Security Rulesを設定してください。デモ用コードは本番の認証情報として使用しないでください。

## ドットカフェのデザイン

水玉模様とレトロポップな色使いをテーマに、文化祭で立ち寄りたくなるカフェの注文ページにしています。メニューはドットラテ、しゅわしゅわソーダ、水玉クリームケーキ、ドットクッキーです。以前のメニューがブラウザに保存されている場合も、在庫数を保ったまま新しいメニュー名に切り替わります。
